# 中期检查结构块组合分页回归设计

## 方案

扩充 `templates/midterm/fixtures/extreme-pagination.json`，在首张正文数据表后插入一条
带稳定 ID 的安全公式，并由前置正文使用 `{{eq:<id>}}` 引用。原有长正文、两张正文表、
进展表和四组组合图片保持不变，使一份夹具同时经过多页表单的全部结构块路径。

## 自动断言

- 数据准备阶段检查两张正文表、一条公式、四组组合图及公式编号解析；
- DOCX 阶段检查三张嵌套表、原生 OMML、公式行 `cantSplit`、无边框公式容器和右对齐编号；
- LaTeX 阶段检查受限数学结构、编号和引用均已解析，不出现原始输入命令；
- PDF 阶段沿用 A4、字体嵌入、中文字形、连续边框、固定栏目和页数窗口门禁，并确认公式
  编号、末组图号和图片对象存在。

## 约束

本实现只增加匿名夹具和断言。所有结构块继续使用公共 Schema 与现有 Word/LaTeX 渲染器，
不形成新的生产数据协议。
