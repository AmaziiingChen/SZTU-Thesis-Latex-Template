# 过程文档页数上界回归需求

## 范围

只扩充开题报告、任务书和中期检查的匿名分页压力回归。毕业论文模板不在本阶段范围内。
历史样本提供页数与内容形态边界，但不提供可复制正文或版式测量值。

## 验收标准

1. 当运行开题报告上界夹具时，LaTeX/PDF 应生成 8–9 页 A4 文档，并通过现有中文字形、
   连续边框、固定签署区和内容提取门禁。
2. 当运行任务书上界夹具时，LaTeX/PDF 应生成 10–12 页 A4 文档，并保持封面、须知、
   连续正文表、选题信息和审批区完整。
3. 当运行中期检查上界夹具时，LaTeX/PDF 应生成 15–17 页 A4 文档，学生正文自然增长，
   教师评价和审查小组区域不得被压缩、代填或拆乱。
4. 压力输入应由公开匿名基础夹具和确定性配方生成，不得包含真实姓名、学号、题目、正文、
   教师意见、签名、原始文件名或路径。
5. 为达到页数上界，系统不得改变官方字号、字体、行距、页边距、表格测量值或签署空间。
6. Word 与 LaTeX 应读取同一份生成后的有效 Schema 数据；压力配方不得成为新的生产输入格式。

## 非目标

- 不要求每个历史页数都各建一份夹具；
- 不把页数本身作为正式文档合格条件；
- 不执行 Word/WPS 人工验收；
- 不修改毕业论文模板。
