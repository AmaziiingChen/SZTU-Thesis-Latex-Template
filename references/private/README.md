# 本地参考资料

此目录除本说明外均被 Git 忽略。可按材料类型放入：

- `theses/`：毕业论文；
- `proposals/`：开题报告；
- `task-books/`：任务书；
- `midterm/`：中期检查；
- `other/`：其他本地参考材料。

完整历史批次按“材料类型/届别完整样本/原始目录结构”归档。例如：

- `proposals/2026届完整样本/`：开题报告完整批次；
- `task-books/2026届完整样本/`：任务书完整批次；
- `midterm/2026届完整样本/`：中期检查完整批次。

此前单独挑选的少量代表文件统一放在各材料类型的 `历史抽样/` 子目录，不与完整批次
混放，也不作为官方格式原件。学校正式发布的空白表格和规范仍只放在 `references/official/`。

历史材料仅用于发现通用排版边界。姓名、学号、正文、签名、教师意见和原始文件名
不得复制到公开夹具、测试日志或 Git 提交中；回归测试只使用重新编写的匿名合成数据。
