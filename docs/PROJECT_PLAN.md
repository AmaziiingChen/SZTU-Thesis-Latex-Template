# SZTU 本科毕业论文 LaTeX 项目计划

## 项目目标

本项目以现有的深圳技术大学本科毕业论文 LaTeX 模板为基础，逐步建立一套学生可直接使用、指导教师可验收、能够跨平台编译的本科毕业设计文档工具链。

项目不只提供毕业论文模板，还将覆盖开题报告、任务书、中期检查等过程文档，并配套入门视频与 Agent 辅助写作指南。

## 阶段与成果

| 阶段 | 主要工具 | 阶段性成果 | 验收要点 |
| --- | --- | --- | --- |

## 支持环境

- macOS：MacTeX/TeX Live + Texifier，命令行默认使用 `latexmk -xelatex`。
- Windows：TeX Live + TeXstudio，编译器使用 XeLaTeX，文献链使用 `xelatex -> bibtex -> xelatex -> xelatex` 或 latexmk。
- 编码：全部源文件使用 UTF-8。
- 字体：优先使用系统规范字体，缺失时使用同类开源/系统字体回退；不在仓库中新增分发来源不明的商业字体。

## Agent 使用边界

Agent 适合处理 LaTeX 结构搭建、格式修正、错误定位、图表与参考文献格式转换、重复性编译和 PDF 检查。下列内容仍需由学生和指导教师负责：

- 论文研究、数据、结论与学术贡献的真实性。
- 文献来源、引用页码和参考文献条目的准确性。
- 学校、学院和当年通知之间冲突时的最终口径。
- 学术诚信、隐私信息和未公开材料的合规使用。

## GitHub 协作策略

1. 保留 `SZTU-ACM/SZTU-Thesis-Latex-Template` 为 `upstream`。
2. 在个人或团队 GitHub 账号下 fork，作为日常开发仓库 `origin`。
3. 通用且不改变上游项目边界的修复（跨平台编译、格式纠错、文档改进）通过 Pull Request 回馈上游。
4. 开题报告、任务书、中期检查、视频教程和 Agent 指南先在 fork 中完成；是否并入上游，由上游维护者根据项目范围决定。
5. 所有新增内容保留上游版权与 GPL-3.0 许可说明，第三方字体、图片和学校文件须单独核对可分发性。
