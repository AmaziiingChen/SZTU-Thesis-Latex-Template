# 2026 届过程文档历史样本审查

审查日期：2026-09-02。

## 1. 范围与证据边界

本轮只把历史学生材料作为内容承载、分页和异常输入的压力样本，不把其中的列宽、
行高、字体、边距或签名空间当作格式权威。三类模板的测量值仍只服从
`references/official/` 与各文档的 `spec/`。

私有材料保存在 `references/private/`，不进入 Git。本文只记录匿名聚合统计和通用能力
缺口，不记录姓名、学号、题目、正文、教师意见、签名、原始文件名或 OCR 文本。

证据分为三层：

1. PDF 结构统计：页数、页面尺寸、旋转、文字层、图像对象、注释与解析状态；
2. 中文字形门禁与逐页检查：只对具有可提取中文文字层、且门禁通过的抽样 PDF 作版式结论；
3. 扫描件 OCR/视觉抽样：只用于发现内容形态，不能替代中文字形门禁或 Word/WPS 验收。

## 4. 开题报告特点

### 稳定共性

- 顶部题目和学生基础信息之后，正文按选题意义、研究内容、研究方法与步骤、参考文献组织；
- 学生签名、指导教师意见与学院意见属于人工填写区，生成器必须保持为空；
- 典型文档为 3–4 页，但页数不是验收条件；
- 长题目、长学院/专业、连续正文、分层列表、科学上下标和长参考文献均是常见压力源；
- 正文外框和分区横线必须在自然跨页时保持连续、闭合。

### 压力边界

- 2–5 页已覆盖绝大多数样本，仍存在 1、6、7、9 页异常或极端输入；
- PDF 来源混杂，包含 A4、Letter、旋转页、扫描原始大页面和裁切高度不一致的页面；
- 少量文件带非表单注释或属于错误归档/跨类别重复，不能以页面尺寸、注释数或文字层
  作为模板合规判据；
- 当前公开开题报告回归中，参考文献数量和极端页数覆盖仍弱于完整历史批次。

## 5. 中期检查特点

### 稳定共性

- 顶部为学生信息、检查日期和论文题目；
- 学生填写区包含论文目录/主要研究内容与工作进展；目录层级和正文列表是不同语义；
- 后部为固定教师评价、后期指导意见、审查小组意见和签名区，均不得由学生数据代填；
- 整体应表现为连续表格，但正文必须按内容自然增高和跨页，不能固定为 3 页；
- 历史样本中可见多种统一编号体系，当前结构化目录编号模型与这一需求一致。

### 压力边界

- 最长样本达到 17 页，包含连续文字、整页实验图、多子图、图题和手工签批区；
- 发现正文内数值表格、图表混排和显示型分式公式；这些不是普通段落或单张图片可以
  完整表达的结构；
- 存在接近空白的尾页、旋转页、Letter 页面、混合页面框和损坏 PDF，导入诊断应区分
  “物理页面”与“有效内容页面”；
- 当前 `long-with-image` 只有两张图片，未覆盖长篇多图、组合图和正文内表格。

## 6. 任务书特点

任务书完整批次此前已完成专项审查并转化为匿名回归夹具。其历史材料主要表现为固定封面、
须知、连续正文表、日期型进度安排、参考资料、选题属性/来源、复选框和审批签章区。
批次版面比开题报告和中期检查更一致，但仍必须覆盖 2、4、6、8、10、12 页内容量、
长参考文献、跨页图片、空白插页和签批区保留。

## 7. 公共能力与文档专属能力

应继续保留在 `templates/common/` 的能力：

- 一份结构化数据同时驱动 Word 与 LaTeX；
- 确定字体、中英混排、中文字号、粗体/斜体/上下标 run；
- 段落、最多四层正文列表、参考文献和自然分页；
- 连续跨页边框、题目自动换行、固定人工填写区；
- 图片、替代文本、尺寸与题注；
- 字体、A4、边框、中文字形和目标编辑器验收彼此独立的 QA 状态。

仍应保持为文档专属的结构：

- 开题报告：9 行、7 网格列和四个正文槽位，以及三类人工区；
- 中期检查：15 行、4 列合并结构、目录与双正文区、教师固定评价和两类意见区；
- 任务书：封面、固定须知、正文表、日期进度、资料/文献、选题复选框和审批区。

## 8. 建议回归矩阵

| 优先级 | 匿名夹具 | 覆盖目标 |
| --- | --- | --- |
| P0 | `common-rich-run-pagination` | 中英混排、上下标、长题目、列表、长参考文献、跨页边框和签名区 |
| P0 | `scan-only-no-text-layer` | 扫描件进入 OCR/人工队列，不误报内容为空或字形通过 |
| P0 | `cross-document-manifest` | 三件套缺失/额外、同名碰撞、跨类别字节重复和解析失败 |
| P1（页数已落实） | `proposal-page-range-and-references` | 1–9 页、极长参考文献、异常页面来源和续页闭合 |
| P1（页数已落实） | `midterm-outline-image-17p` | 六级目录、双正文区、长篇多图、教师区不可拆分 |
| P1 | `midterm-table-equation-figure-group` | 正文表格、显示公式、多子图和题注原子分页 |
| P1（页数已落实） | `taskbook-2-to-12p` | 典型页数阶梯、日期进度、图片、复选框、空白插页与签批区 |
| P2 | `mixed-pdf-import-diagnostics` | 混合纸张、旋转、注释、空白尾页、引擎回退和损坏隔离 |

其中正文表格、显示公式和多子图组合属于明确的数据模型缺口，应先补规格、匿名夹具和
自动断言，再实现 Word/LaTeX 双路渲染。PDF 导入诊断属于工作台输入质量能力，不应混入
文档模板的排版测量值。

### 已落实的 P0 输入诊断

- `scan-only-no-text-layer`：公共 PDF 证据状态已区分 `text_layer`、`scan_only`、
  `no_text_evidence`、`encrypted` 与 `parse_failed`；扫描件只进入 OCR/人工队列；
- `cross-document-manifest`：匿名清单已覆盖三件套缺失、同类多份冲突、跨类别字节重复、
  未支持类型和单文件解析失败隔离；
- 输出只保留本机盐值生成的匿名 ID、文件哈希和结构统计，不含原始键、文件名、路径或
  提取文字；
- 混合纸张、旋转、有效内容页判定和第二 PDF 引擎回退仍属于 P2，未在本阶段标记完成。

### 已落实的页数压力回归

公共匿名压力配方现已覆盖历史批次的上界窗口，当前 LaTeX/PDF 实际结果为：开题报告
8 页、任务书 10 页、中期检查 17 页。三类结果均通过 A4、中文字形、连续边框、固定栏目、
内容提取和无缺字门禁；代表性的中文密集页与末页签署区也已按原始比例检查。

这些页数仅用于证明模板能承受历史样本中观察到的内容规模，不是正式文档的合格条件。
压力数据由公开匿名夹具确定性生成，不复制历史正文，也不通过缩小字号、行距、页边距、
表格尺寸或签署空间追求页数。Word/WPS 目标编辑器验收仍是独立门禁，本阶段未执行。
