# 毕业论文工作台适配约定

软件侧实施约定见同级 `SZTU-Graduation-Docs-Studio/docs/THESIS_WORKBENCH.md`。

本分支从 `f0b1e3d` 模板基线开始；模板继续以现行官方格式、artifact.md 和 layout.json 为版式权威。
首次接入只增加结构化内容到现有 LaTeX 模板的映射，不另写一套排版引擎。

- 学生档案映射到 info.tex；摘要、关键词、章节、致谢与附录写入各自生成文件。
- 图表、公式、章节的语义 ID 映射为经过校验的 label，引用由编译器生成编号。
- 文献规范沿用现有 GB/T 7714 数字顺序制，输出只包含实际引用条目。
- 用户普通文本必须转义，不将普通编辑内容视作可执行 LaTeX；图片从托管资源白名单复制。
- 导出目录只存输入快照和当前作业产物，不修改原始模板和仓库内容。
- 包含字体检查、编译失败、缺失资源、引用失效的结构化报错；失败不覆盖已验证文件。
- 校验沿用 thesis/test.py 与中文字形门禁，再添加针对结构化输入的合成回归。

已实现结构化论文到原模板的 PDF 渲染入口。封面提交日期由草稿显式填写；旧草稿缺少该字段时可继续编辑，补填后才能导出。普通文本逐字转义，数学源码只接受受限命令集；失效引用、非托管图片、最终编译仍有缺字或未解析引用时停止交付。

截至 2026-10-04，软件的毕业论文页面已调整为 LaTeX 起始工程下载，原正文编辑、预览和文档导出入口收起。本目录保留原结构化渲染能力及测试，供后续维护；源码存在不表示当前界面已开放该功能。起始工程下载与把用户草稿导出为 LaTeX 工程是不同流程。
