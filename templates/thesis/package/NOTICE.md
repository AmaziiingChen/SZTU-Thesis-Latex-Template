# 模板来源与修改说明

本工程继承自 SZTU-ACM/SZTU-Thesis-Latex-Template，保留上游作者贡献与 GPL-3.0 许可。

- 上游仓库：https://github.com/SZTU-ACM/SZTU-Thesis-Latex-Template
- 上游基线：3e51a3db7b0af1469490712b3a6924bbefc574dd
- 校准维护仓库：https://github.com/AmaziiingChen/SZTU-Thesis-Latex-Template
- 本包适用规格：本项目收录的 2026 届本科毕业论文格式。
- 本地修改：官方格式校准、严格字体解析、参考文献排版、学生起始内容、中文注释、Agent 指引和可移植打包。具体文件版本见 template-manifest.json。

gbt7714.sty 与 gbt7714-numerical.bst 来自 CTeX-org/gbt7714-bibtex-style，沿用文件头中的 LaTeX Project Public License 声明。本项目固定随附版本，不因系统包更新自动替换。

封面校名素材 images/school_title.pdf 沿用上游文件，仅作为学校论文封面素材使用；本包不授予学校标识的额外使用权。学校正式 Word 文件、商业字体、个人信息、签名和已生成论文均不随包提供。

本包的用途是辅助写作和排版，不构成学校或导师对任何学生论文的预先验收。
