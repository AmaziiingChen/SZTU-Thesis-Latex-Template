# 毕业论文工程协作约定

本文件服务于下载工程的学生及其 Agent。先阅读 README.md、用户最新要求，以及待编辑文件的中文注释。默认使用简体中文沟通。

## 确认任务和事实

- 内容文件以学生提供的材料为准。区分原始数据、作者判断、文献结论和待补信息。
- 不编造实验、数据、结果、作者、文献、DOI、签名或导师意见。缺少资料时先完成有依据的部分，再集中列出待核实项。
- 不把本包示例正文、公式或文献当作学生实际研究。替换占位文字时保持原有事实和确定程度。
- 用户没有要求改格式时，保持官方版式。不要为了压缩页数缩小字号、行距、页边距或签署空间。

## 文件边界

- 优先修改 content/、thesis-references.bib 和用户自己的 images/。章节可按需拆文件，主入口始终为 sztuthesis_main.tex。
- SZTUthesis.cls 是排版引擎；sztuthesis_main.tex 是装订入口。确需改动时，说明依据，检查 docs/artifact.md 与 docs/layout.json，并验证影响范围。
- 不手改生成的 PDF、.bbl、.aux、.toc。不要把机器字体路径写入共享源码。
- 保护已有修改。覆盖无法恢复的文件前保留可恢复版本；不使用 git clean 或按忽略规则递归清理资料。
- 不在未获授权时上传论文、学生信息、数据或字体，也不创建公开仓库或发布包。

## LaTeX 语义

- 使用 section、subsection、subsubsection 组织层级，标题内不写手工编号；本类不提供 chapter。
- 段落之间空行，普通段落由模板缩进。不能用空格、制表符或多次换行模拟排版。
- 图表用 caption 和唯一 label，正文用 ref；公式用 equation/align 和 eqref；文献用 cite。
- 数学上下标用下划线/脱字符及大括号，不使用 Unicode 上下标来伪装结构。
- 三线表保留真实表格结构。长表采用 longtable，重复表头；不要缩放整页或把表格转成图片掩盖超宽。
- 普通文本里的特殊字符要转义：百分号写作 `\%`，与号写作 `\&`，下划线写作 `\_`。文件统一 UTF-8。

## 编译和检查

1. 先确认 TeX Live/MacTeX、Python 和必需字体。运行 `python3 scripts/build_thesis.py`，Windows 使用 `py -3`。
2. 失败先处理日志中的第一个错误，不在失败后交付旧 PDF。缺字体应修复环境，不替换字体。
3. 检查最终日志的缺字、未定义引用和超出边界；确认正文中的研究内容没有为通过检查而丢失。
4. 有 Poppler 与 Pillow 时，可用 `pdftotext` 提取文字、以 180 DPI 渲染单页，再运行 `python3 scripts/validate_cjk_render.py sztuthesis_main.pdf`。字形门禁失败就停止视觉结论。
5. 检查中文密集单页原图后再逐页审阅；联系表只供导航。未检查的页面明确标出，不能把成功生成 PDF 当作已验证全部版式。
6. 最终向学生说明改了哪些内容、编译结果、检查范围和剩余待补项。研究真实性与学校最终验收仍由作者及导师负责。

本包不包含模板维护仓库的全部回归样例；不要要求学生安装整个桌面工作台来编译论文。
