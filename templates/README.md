# 过程文档模板

现有毕业论文模板暂时保留在仓库根目录。本目录用于逐步增加：

- `common/`：各模板复用的信息与版式组件；
- `proposal/`：开题报告；
- `task-book/`：任务书；
- `guidance-record/`：指导过程记录；
- `midterm/`：中期检查；
- `review/`：指导教师评审、评阅、答辩和成绩表；
- `archive/`：诚信声明、档案袋封面等归档材料。

`common/` 是实际运行的公共层，不是示例目录。新模板应复用其中的富文本 Schema、中文
字号映射、字体政策、段落/列表处理和 PDF 几何断言；列宽、行高、签署区等具体尺寸仍由
各模板自己的 `spec/` 定义。完整方法见
[`docs/TEMPLATE_ENGINEERING_GUIDE.md`](../docs/TEMPLATE_ENGINEERING_GUIDE.md)。
